  \item[Presenters.] All four members, each introducing themselves and their part: Tushar B

\section{Innovation features shown}
Voice input (02:16), AI-assisted classification with confidence and a fallback (02:39), duplicate
detection while typing (03:12, 06:57), smart assignment with explanations (04:03), Telegram and
Gmail alerts (04:24), Google Sign-In (01:22), configuration without code changes (09:11), the live
service health map (10:31), suggested fixes from similar incidents (14:08) and chatbot reporting
(14:18).
